## Reporting a Vulnerability

We take the security of ArabicPDF seriously. Because ArabicPDF is designed to run entirely locally without sending any data over the network, data privacy is a core architectural promise.

If you discover a security vulnerability (such as an arbitrary code execution vector via maliciously crafted PDF files), please report it responsibly:

1. **Do not open a public issue.**
2. Send an email to `youssefdev74@gmail.com` with:
   - A description of the vulnerability.
   - Steps to reproduce or a minimal proof-of-concept.
   - Potential impact.
3. You will receive an acknowledgment within 48 hours.
4. We will coordinate a patched release before any public disclosure.
